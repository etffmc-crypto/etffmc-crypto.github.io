Privacy policy

Last updated: October 12, 2026

Ryda Clips is a private tool used only by the owner of the YouTube channel @rydamoments to upload video clips to that channel.

What it accesses

With the channel owner's Google sign-in, Ryda Clips uses the YouTube Data API only to upload videos and set their titles, descriptions, thumbnails and publish times on the owner's own channel.

What it stores

The sign-in token is kept only on the owner's own computer. Ryda Clips does not collect, sell or share personal information, and it does not access data belonging to anyone else.

Google API data

Ryda Clips' use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.

Contact

Questions: open an issue at github.com/etffmc-crypto/etffmc-crypto.github.io.
